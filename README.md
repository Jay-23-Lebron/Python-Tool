# Python Project
## Project Introduction
This is a basic Python practice project for programming learning.

## Directory Structure
src/
├─ **init**.py
├─ main.py
├─ logic.py
└─ data.py
- main.py：Program entry file, start the whole program
- logic.py：Core business function processing
- data.py：Data storage module
- __init__.py：Mark this folder as a Python module

## How to run
1. Open the project with VS Code
2. Run main.py directly to start the program

## Learning Purpose
Build a standard project structure, learn modular programming, and continuously expand functions later.
